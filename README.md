## 🚀 Flagship Projects

<details open>
<summary><b>1. 🧠 RAGX: Production-Oriented Multi-Tenant RAG Platform</b></summary>
<br/>

- **Description:** Enterprise-ready multi-tenant Retrieval-Augmented Generation platform built with document ingestion, hybrid vector + lexical retrieval, and knowledge-graph routing.
- **Key Highlights:**
  - **Hybrid Search & GraphRAG:** Fuses vector and BM25 search via Reciprocal Rank Fusion (RRF), refined through cross-encoder reranking and MMR. Achieved **71.5% Exact Match** with GraphRAG (vs 48.2% baseline vector search) at **76.5 F1** and **0.86 nDCG**.
  - **Citation & Fallback:** Citation-aware generation with LLM routing and automatic fallback (Gemini & Groq), backed by semantic caching.
  - **Strict Security:** Enforced robust multi-tenant data isolation — **11/11 security tests passed** with 0 leaks, and **47/47 regression tests passing**.
- **Tech Stack:** Python, FastAPI, PostgreSQL, Redis, Docker, Streamlit, Gemini, Groq, PyTest.
</details>

<details open>
<summary><b>2. 🏥 FedMedVision: Privacy-Preserving & Explainable Federated Medical AI</b></summary>
<br/>

- **Description:** Federated Learning healthcare platform training vision models across hospital silos without centralizing sensitive patient clinical data.
- **Key Highlights:**
  - **Multi-Hospital FL:** 6-hospital simulated federated learning system using **ConvNeXt-Tiny + FedBN + FedProto** across **20,000+ chest X-rays** (NIH ChestX-ray14, CheXpert, VinDr-CXR), yielding an **11% AUROC boost** over isolated institutions.
  - **Differential Privacy & Byzantine Defense:** Differential Privacy via **Opacus ($\varepsilon = 7.82$)**, Trimmed-Mean Byzantine aggregation against poisoning attacks, and an immutable SHA-256 EU AI Act compliance audit ledger.
  - **Clinical Interface:** Streamlit radiology dashboard featuring full DICOM windowing, Grad-CAM++ lesion localization verified against radiologist bounding boxes, and automated PDF clinical reporting (**76/76 unit & integration tests passing**).
- **Tech Stack:** PyTorch, Flower (FL), Opacus, ConvNeXt-Tiny, Streamlit, PyDicom, ReportLab, PyTest.
</details>

<details open>
<summary><b>3. 🤖 MLForge: Multi-Agent Autonomous ML Engineering Platform</b></summary>
<br/>

- **Description:** Autonomous multi-agent engineering platform that converts natural-language problem specifications into end-to-end production ML pipelines.
- **Key Highlights:**
  - **LangGraph Multi-Agent Architecture:** Specialized cooperating agents handle planning, dataset EDA, feature engineering, model selection, hyperparameter tuning, evaluation, and debugging.
  - **Self-Correction Loops:** Agents interpret test failures and poor validation metrics to iteratively debug and refine pipelines autonomously.
  - **Microservice Design:** FastAPI backend, PostgreSQL persistence, and Pydantic schemas, containerized with Docker.
- **Tech Stack:** LangGraph, Python, FastAPI, PostgreSQL, Docker, Scikit-learn, XGBoost, Pydantic.  
[View Repository](https://github.com/Devadn11206/MULTI_AI_AGENTS)
</details>

<br/>

- **Description:** Distributed multi-agent traffic signal control incorporating physics-based flow dynamics to alleviate city grid congestion.
- **Key Highlights:**
  - **Multi-Agent RL Benchmarks:** Implemented and benchmarked **CoLight, PressLight, and IDQN** agents in SUMO and TraCI across multiple real-world traffic network topologies.
