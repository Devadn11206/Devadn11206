## 🔬 Published Research

### Analysis of nonlinear Schrödinger equations with anticubic nonlinearity in optical fiber systems via physics informed neural network (PINN)

**Journal:** *Chaos, Solitons & Fractals* — Elsevier  
**Article Number:** 119133  
<a href="https://doi.org/10.1016/j.chaos.2026.119133"><img src="https://img.shields.io/badge/DOI-10.1016%2Fj.chaos.2026.119133-8A2BE2?style=for-the-badge&logo=elsevier&logoColor=white" alt="DOI" /></a>

This research investigates Physics-Informed Neural Networks for modeling nonlinear Schrödinger equations with anticubic nonlinearity in optical fiber systems. The work focuses on PINN-based PDE solving, nonlinear wave dynamics, neural-network-based scientific computing, physics-informed loss functions, and rigorous numerical validation.
